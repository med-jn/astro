# خريطة طريق «عين الراصد» — العمل المؤجل (يُراعى في كل تعديل قادم)

## الغلاف الجوي العلمي (مؤجل بطلب المستخدم، يجب إنجازه)
مدخلات يتحكم بها المستخدم: الحرارة، الضغط، الرطوبة النسبية، الهباء، الأوزون، الارتفاع، (الطول الموجي).
نتائجها يجب أن تكون دقيقة وقابلة للتحقق: الانكسار (مع تصحيح الضغط/الحرارة والرطوبة والتشتت اللوني)، الانخماد بالكتلة الهوائية،
التشتت (رايلي/ميه)، لون الشمس والسماء عند الشروق والغروب، وتأثيرها على القمر والكواكب والنجوم.
- هيكل المدخلات موجود: `src/core/atmosphere.ts` (بلا فيزياء بعد).
- شرط الاعتماد: مطابقة كل صيغة مع مرجعها المنشور بجدول اختبار، وعدم استعمال رقم دون مصدر.

## بيانات تحتاج مصادر خارجية
القمر: خرائط LRO (LOLA + WAC) وجبر الاهتزاز؛ البقع الشمسية: NOAA SWPC وSDO/HMI وSILSO؛ درب التبانة: Gaia؛ الأفق: بانوراما HDRI ونسيج PBR ممسوح.

## قيد التنفيذ لاحقاً
التيليسكوب (قناع عدسية، أطوال بؤرية، بصريات)، ظل الحلقات على زحل، البقعة الحمراء، أقمار الكواكب الأخرى، توهج أفق الكسوف الكلي.

## مصادر تم التحقق منها (وما لم يُتحقق منه)
- بكسل CSS المرجعي ≈ 0.0213° عند ذراع 28 بوصة: W3C CSS Values and Units («Reference Pixel») — متحقَّق.
- حدود حلقات زحل: PDS Rings Node (pds-rings.seti.org/saturn/saturn_rings_table.html) — متحقَّق (A: 122,050–136,770 كم؛ كاسيني: 117,500–122,050).
- أنصاف أقطار الكواكب (IAU WGCCRE 2015 / جداول ناسا) وأقطاب الدوران: من الذاكرة — **لم تُتحقق بعد**.
